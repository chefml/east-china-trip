# East China Trip 2026

Офлайн-первый PWA-справочник поездки по Восточному Китаю 27 октября – 12 ноября 2026: Шанхай → Ханчжоу → Хуаншань → Нанкин (с днём в Сучжоу) → Шанхай. Статика без сборщика и без внешних CDN: открывается с домашнего экрана телефона и работает в авиарежиме.

**Живая версия:** https://chefml.github.io/east-china-trip/

## Возможности

- Расписание по дням (17 дней, 27 октября – 12 ноября), горизонтальные вкладки-чипы
- Заголовок дня: дата, описание, загруженность в виде 5 звёзд
- Карточка активности: время, название, заметка, бейджи категории/приёма пищи/«опционально»; тап по карточке раскрывает описание места (`location.details`)
- Кнопка **«Проложить маршрут»** → Google Maps directions, вторичная ссылка **«На карте»**
- **«Маршрут по точкам дня»** — одна ссылка со всеми остановками дня по порядку
- Четыре раздела: Маршрут · О поездке · Ужин · Как пользоваться
- Три языка: English, Русский, 中文 — переключатель в разделе «Как пользоваться», выбор запоминается
- Тема переключается автоматически по времени суток телефона: светлая 07:00–19:00, тёмная ночью
- Полностью офлайн после первой загрузки (service worker, network-first с фолбэком в кэш)

## Установка на телефон

Открыть ссылку выше в Safari (iOS) или Chrome (Android) → **Share → Add to Home Screen**. Один раз запустить приложение с сетью, чтобы service worker закэшировал файлы; после этого работает офлайн. Переходы в Google Maps требуют сети или офлайн-карт.

## Локальная разработка

Service worker требует http(s), `file://` не подойдёт:

```bash
npx serve
```

## Структура

```
index.html                        разметка и контейнер приложения
styles.css                        весь CSS, mobile-first, светлая и тёмная темы
app.js                            загрузка данных, рендер, i18n, deep links, регистрация SW
east-china-trip-data.i18n.json    данные поездки на трёх языках
manifest.json                     манифест PWA
sw.js                             service worker, network-first + кэш
icons/                            icon.svg — источник, icon-192.png, icon-512.png
east-china-pwa-spec.md            исходное техническое задание (от шаблона Chiang Mai)
```

Иконки пересобираются из `icons/icon.svg`:

```bash
rsvg-convert -w 192 -h 192 icons/icon.svg -o icons/icon-192.png
rsvg-convert -w 512 -h 512 icons/icon.svg -o icons/icon-512.png
```

## Данные

Всё содержимое — в `east-china-trip-data.i18n.json`. Текстовые поля (`trip.title`, `trip.overview`, `day.title/focus/roads/clothing/extra`, `day.weekday`, `location.name/note/details`, `dining.*`, `general.*`, `appGuide.*`, `legend.*`) — объекты `{en, ru, zh}`. Строки интерфейса — в `ui` по коду языка. Коды `category` и `meal` языконезависимы, подписи берутся из `ui[lang].categories` / `ui[lang].meals`. Категории этой поездки включают `transit`, `museum`, `sight`.

Приложение оставляет у `trip.title` только первые два сегмента, разделённые тире, поэтому заголовок должен состоять не более чем из двух частей.

## Обновление

1. Отредактировать `east-china-trip-data.i18n.json`
2. Поднять версию кэша в `sw.js` (`ec-trip-vN` → `ec-trip-vN+1`)
3. `git add -A && git commit -m "..." && git push`

На телефоне приложение подтянет новую версию при следующем онлайн-открытии.
